💡 Informações

⚙️ Como usar

  • Clique em ⚙️ Editar para modificar uma conexão
  • Use ▶️ Ativar/⏸️ Desativar para controlar
  • Clique em 🗑️ Deletar para remover

🔌 Ethernet vs 📶 Wi-Fi

  • Ethernet: Conexão cabeada (mais estável)
  • Wi-Fi: Conexão sem fio (mais flexível)
  • Você pode ter ambas ativas simultaneamente

🌐 Tipos de IP

  • DHCP: IP automático do roteador
  • Estático: IP configurado manualmente
  • Clique para copiar IPs com ícone 📋
